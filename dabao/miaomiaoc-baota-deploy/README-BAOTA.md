# MiaomiaoC 宝塔部署包

上传整个压缩包到 `/www/wwwroot/miaomiaoc` 后解压。

关键路径：

- 前端站点根目录：`/www/wwwroot/miaomiaoc/frontend`
- 后端 jar：`/www/wwwroot/miaomiaoc/backend/backend-0.0.1-SNAPSHOT.jar`
- 后端配置：`/www/wwwroot/miaomiaoc/backend/config/application.yml`
- 数据库 SQL：`/www/wwwroot/miaomiaoc/database/miaomiaoc.sql`
- Nginx 配置片段：`/www/wwwroot/miaomiaoc/nginx/miaomiaoc-baota.conf`

部署步骤看 `部署说明.txt`。
