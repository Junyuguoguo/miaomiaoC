# 自动化测试计划

## 项目概述
- 前端：Vue 3 + Vite + Element Plus
- 后端：Spring Boot 4.0.3 + JPA + MySQL + Redis + Spring Security
- 测试框架：Playwright (前端) + pytest + requests (后端)

## 测试数据策略
- 使用独立的测试数据库
- 每个测试用例前后清理数据
- 使用工厂模式创建测试数据
- 避免污染真实数据

## 测试环境要求
- 后端服务运行在 localhost:8080
- 前端服务运行在 localhost:5173
- MySQL 数据库：miaomiaoc_test
- Redis：localhost:6379
